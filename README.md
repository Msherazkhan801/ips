# Iqra Public School Permoli (IPS Permoli)

A modern, full-stack school management system and animated web application built with **Next.js 14**, **TailwindCSS**, and **Firebase**.

## 🌟 Key Features

- **Public School Portal**:
  - Home Page with real campus highlights, academic wings, and principal's message.
  - Separate pages for **About Us**, **Academics** (Pre-School, Primary, Middle, Matric BISE Mardan), **Facilities**, **Photo Gallery**, **Notices**, and **Contact**.
  - **Student Fee Lookup Portal** (`/fee-check`): Real-time fee balance & marks lookup in PKR with printable receipts.
  - **WhatsApp Hotline Support**: Animated floating bubble connecting directly to `03472943510`.

- **Comprehensive Admin Panel** (`/admin`):
  - **Student & Fee Management**: Full student records editing, marks & academic performance tracking (total/obtained marks, percentage, grade distinction), fee collection in PKR, and ledger history.
  - **Site Gallery Manager**: Add, edit, and organize dynamic photos displayed on the live website.
  - **School ID Card Generator**: Dual-sided printable identity badges with circular school emblem, QR/barcodes, and Principal Akhter Munir's seal.
  - **Certificate Generator**: Customizable printable certificates with admin-selected Issue Dates, gold seals, and honors ribbons.
  - **Notice Board & Inquiries**: Manage announcements and admission applications.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Msherazkhan801/ips.git
cd ips

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
